"The Robot Game" was my final, self-directed project for my university robotics course. I opted to develop a game where the player controls both a real Arduino robot and an in-game robot sprite with the purpose of reaching the on-screen goal.

Coded with Godot 4.4 (the C# build!) and sound effects from Freesound. Generative AI was not used in the creation of this game.

I permit the viewing and usage of any of this game's code for any reason. I permit the viewing and limited usage of this game's art, but I do not permit falsely claiming the art as your own or using it to train generative AI models.
